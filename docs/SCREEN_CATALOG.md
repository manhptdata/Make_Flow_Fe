# Danh mục màn hình

| Nhóm       | Route                                                                                            | Mục đích                           |
| ---------- | ------------------------------------------------------------------------------------------------ | ---------------------------------- |
| Auth       | `/login`                                                                                         | Đăng nhập phiên an toàn            |
| Setup      | `/setup/workspace`                                                                               | Khởi tạo workspace, chi nhánh, kho |
| Dashboard  | `/dashboard`                                                                                     | KPI vận hành                       |
| Catalog    | `/catalog/units`, `/catalog/items`, `/catalog/products`                                          | Danh mục chung                     |
| Recipe     | `/recipes`, `/estimates`                                                                         | Công thức và ước tính sản xuất     |
| Inventory  | `/procurement/receipts`, `/inventory/balances`, `/inventory/movements`, `/inventory/adjustments` | Nhập và kiểm soát kho              |
| Production | `/production`, `/production/:id`                                                                 | Giao việc, hoàn thành, đạt/hỏng    |
| POS        | `/pos`                                                                                           | Bán hàng tại quầy                  |
| Sales      | `/sales/orders`                                                                                  | Lịch sử đơn hàng                   |
| Reports    | `/reports/inventory`, `/reports/quality`, `/reports/gross-profit`                                | Báo cáo vận hành                   |
| Admin      | `/admin/users`, `/admin/roles`, `/admin/settings`                                                | Quản trị                           |
| Operations | `/audit`, `/jobs`, `/imports`                                                                    | Audit và tác vụ nền                |
